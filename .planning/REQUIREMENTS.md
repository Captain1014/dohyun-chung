# Requirements: Google Cloud Customer Engineer Preparation

**Defined:** 2026-03-26
**Core Value:** Master Google Cloud services deeply enough to confidently demonstrate technical expertise and customer-facing solution design in the CE interview process.

## v1 Requirements

Requirements for complete CE preparation (6-month timeline). Each maps to roadmap phases.

### GCP Foundation

- [ ] **FOUND-01**: Understand GCP resource hierarchy (Organization > Folder > Project > Resource) and how it differs from AWS
- [ ] **FOUND-02**: Master IAM roles, service accounts, and policy inheritance in GCP
- [ ] **FOUND-03**: Configure and operate Compute Engine instances (create, manage, autoscale)
- [ ] **FOUND-04**: Use Cloud Storage (buckets, classes, lifecycle, access control) and map to S3 concepts
- [ ] **FOUND-05**: Set up VPC networks, subnets, firewall rules, and understand GCP's global VPC model vs AWS regional VPC
- [ ] **FOUND-06**: Deploy and manage Cloud SQL and understand managed database options
- [ ] **FOUND-07**: Map all major AWS services to GCP equivalents with clear understanding of differences
- [ ] **FOUND-08**: Complete 20+ hours of hands-on labs on Cloud Skills Boost (Qwiklabs)
- [ ] **FOUND-09**: Proficiently use gcloud CLI for all common operations (compute, storage, IAM, networking)
- [ ] **FOUND-10**: Understand BigQuery fundamentals (serverless data warehouse, SQL analytics)

### ACE Certification

- [ ] **ACE-01**: Master Domain 1 — Setting up a cloud solution environment (IAM, billing, resource hierarchy)
- [ ] **ACE-02**: Master Domain 2 — Planning and configuring a cloud solution (pricing, compute, storage, networking planning)
- [ ] **ACE-03**: Master Domain 3 — Deploying and implementing a cloud solution (Compute Engine, GKE, Cloud Run, Cloud Functions, data solutions, networking)
- [ ] **ACE-04**: Master Domain 4 — Ensuring successful operation (monitoring, logging, Cloud Operations suite)
- [ ] **ACE-05**: Master Domain 5 — Configuring access and security (IAM, service accounts, audit logs)
- [ ] **ACE-06**: Achieve 80%+ on timed practice exams consistently before booking real exam
- [ ] **ACE-07**: Understand Terraform basics for GCP infrastructure provisioning
- [ ] **ACE-08**: Deploy and manage GKE clusters (Autopilot and Standard modes)
- [ ] **ACE-09**: Pass Associate Cloud Engineer certification exam (June 2026)

### AI/ML & Cloud Next '25

- [ ] **AIML-01**: Understand Vertex AI platform end-to-end (training, tuning, deployment, prediction)
- [ ] **AIML-02**: Demonstrate Gemini 2.5 capabilities (Pro, Flash) and API usage patterns
- [ ] **AIML-03**: Build and configure agents using Vertex AI Agent Builder
- [ ] **AIML-04**: Understand Agent Development Kit (ADK) and A2A protocol from Next '25
- [ ] **AIML-05**: Learn Google Cloud Next '25 key announcements (Ironwood TPU, Cloud WAN, Google Unified Security, Gemini in BigQuery)
- [ ] **AIML-06**: Build one demo-able AI project using Vertex AI + Gemini (portfolio piece)
- [ ] **AIML-07**: Articulate Google's AI strategy and competitive advantages vs AWS/Azure AI offerings

### CE Interview Preparation

- [ ] **INTV-01**: Prepare 7-10 STAR stories mapped to Google's 4 hiring attributes (GCA, RRK, Leadership, Googleyness)
- [ ] **INTV-02**: Create 7-slide technical presentation for CE presentation round (real customer scenario)
- [ ] **INTV-03**: Tailor resume to Google CE role — emphasize pre-sales, solution design, customer technical advisory
- [ ] **INTV-04**: Practice whiteboard/architecture design scenarios (GCP-based solution for enterprise customer)
- [ ] **INTV-05**: Complete mock interviews covering all 5 rounds (recruiter, behavioral, technical, presentation, culture fit)
- [ ] **INTV-06**: Prepare AWS-to-GCP migration narrative — position AWS experience as customer empathy asset
- [ ] **INTV-07**: Research Google Korea CE team specifics (specialty tracks, recent hires, team focus areas)

## v2 Requirements

Deferred to after initial CE application. Tracked but not in current roadmap.

### Advanced Certifications

- **CERT-01**: Professional Cloud Architect certification
- **CERT-02**: Professional Machine Learning Engineer certification
- **CERT-03**: Professional Cloud DevOps Engineer certification

### Deep Specialization

- **SPEC-01**: Kubernetes administration deep dive (CKA-level)
- **SPEC-02**: Multi-cloud architecture patterns
- **SPEC-03**: Google Workspace integration and productivity suite knowledge

## Out of Scope

| Feature | Reason |
|---------|--------|
| Professional-level certifications | ACE first; professional certs are post-hire goals |
| Deep Kubernetes/GKE SRE skills | CE needs conceptual understanding, not operator-level depth |
| Non-Google cloud deep dives | Focus exclusively on GCP ecosystem for 6 months |
| Coding interview preparation | CE is not SWE; solution design > algorithm problems |
| Google Workspace admin skills | CE focuses on Cloud Platform, not productivity tools |
| Multi-cloud architecture design | Single-cloud GCP mastery is the priority for interview |
