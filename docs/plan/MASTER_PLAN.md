## 4. 직무별 면접 준비 포인트

### Google CE
- **기술 라운드:** GCP 서비스 설명 + 아키텍처 화이트보딩
- **고객 라운드:** 고객 기술 문제 해결 시나리오 (STAR)
- **핵심 질문:** "AWS 경험을 GCP에 어떻게 적용하겠는가?"

### Notion SE
- **데모:** Notion으로 엔터프라이즈 워크플로우 직접 시연
- **기술:** API 연동, SSO/IdP 기본 개념
- **핵심 질문:** "고객이 기존 툴을 Notion으로 바꿔야 하는 이유를 설명하라"

### OliveYoung TPM
- **PM 역량:** 프로젝트 scope/timeline/resource 관리 사례
- **도메인:** 뷰티/리테일 이커머스 이해
- **핵심 질문:** "여러 팀이 얽힌 프로젝트에서 블로커를 어떻게 해결했나?"

### TossPayments TPM
- **기술 이해:** 결제 플로우 (POS → PG → 정산) 설명 가능해야
- **프로그램 관리:** 복잡한 의존성 관리 사례
- **핵심 질문:** "기술적으로 틀린 방향으로 가는 팀을 어떻게 설득했나?"

### Hopae PM
- **Product sense:** eID/디지털 신원 문제 정의
- **실행력:** 0→1 제품 만든 경험
- **핵심 질문:** "이 제품의 가장 중요한 다음 기능은 무엇인가?"
