# CE 지원 전 준비 (자격증 외)

**목적:** Google Korea Cloud Customer Engineer 채용에서 **ACE만으로는 차별화되지 않는다**는 현직자 프로필 관찰을 반영하고, 지원 전에 갖추면 좋은 역량·증빙을 정리한다.

**전체 실행 순서·월별 타임라인:** [`docs/plan/MASTER_PLAN.md`](../plan/MASTER_PLAN.md)

**관찰 (공개 프로필 샘플, 2026-03 기준):**

| 패턴 | 예시 |
|------|------|
| ACE 없이 장기 CE | 프리세일즈·엔터프라이즈 아키텍처·GKE 중심 경력, 레거시 벤더 자격 위주 |
| ACE 대신 **PCA** + **CKAD** | 비전공/경력 전환·클라우드 전환형 CE |
| **AWS 경력** + GCP PCA | 경쟁사에서 CE로 이동 |

**CKAD (Certified Kubernetes Application Developer)** — **한국 Google Cloud CE 현직자 프로필에서 거의 공통**으로 보인다. 공식 채용 요건 문구와 별개로, **팀 내 기대 역량·교육/자격 지원(응시비·학습 경로 등)과 맞물려 있다는 인상**이 있다. (구체적 지원 조건은 공개되지 않았으므로 **입사 후/채용 담당 확인**이 안전하다.)

→ **ACE는 학습 로드맵·지식 균일화에 유리하지만, 한국 CE의 필수 필터는 아닐 수 있다.**  
→ **CKAD**는 한국 CE 프로필에 많이 보이지만, **현재 개인 플랜에서는 응시하지 않음** — 이력서에 **Software Engineer** 실무가 있으면 K8s/GKE는 **PCA + 경험**으로도 설명 가능. (나중에 필요 시 재검토.)  
→ **고객 대면 기술 영업, 아키텍처, PoC, 특정 수직(금융·통신·제조 등) 또는 AI/데이터 스토리**가 이력서·면접에서 더 자주 드러난다.

## 1. 역량 (자격증과 별개로 준비할 것)

### A. 솔루션 설계·고객 대면 스토리

- **CE 업무에 맞는 언어:** 브리핑, 데모, PoC, 엔터프라이즈 아키텍처 권고, 이후 구현 단계에서의 기술 신뢰(technical trust advisor).
- **STAR/카본 카피:** 복잡한 요구사항을 아키텍처로 풀었던 사례, 이해관계자 조율, 실패·트레이드오프.
- 이미 보유한 **엔터프라이즈 고객 대응·SaaS 런칭** 경험을 GCP 관점(서비스명·아키텍처 패턴)으로 **재서술**할 준비.

### B. GCP 실무 깊이 (시험 범위를 넘어서)

- **핵심:** Compute / Storage / Networking / IAM / 보안 기본 + **데이터(BigQuery 등)**, **GKE·컨테이너 개념**, **Vertex AI·Gemini 생태계** (2026 CE 면접에서 가중치 높음).
- **Hands-on:** 개인 프로젝트 1–2개(아키텍처 다이어그램 + 왜 그 서비스인지 한 문서). ACE 출제 범위만이 아니라 “고객 시나리오” 기준으로 설계.

### C. Kubernetes / GKE (자격증 없이도)

- **CKAD 자격**을 지금 목표에 넣지 않아도, **GKE·컨테이너·배포**는 PCA 시나리오와 면접에서 나온다 — 공식 가이드 + Hands-on으로 **앱 관점**을 맞춘다.
- 이력서상 **SWE**(예: 멀티테넌트, API, 런칭)가 있으면 “앱을 배포·운영해봤다”는 축은 이미 있음; **GCP에서는 어떤 서비스로 그릴지**만 얹으면 된다.
- GKE와 연결해 “왜 GKE인지 / 언제 Cloud Run인지”를 말할 수 있으면 충분한 경우가 많다.

### D. 업계·한국 시장 맥락

- **금융·통신·게임·제조·대기업** 등 레퍼런스/규제·데이터 주권 이슈를 한두 문장으로라도 연결할 수 있으면 좋다.
- **Google Cloud Next**, 주요 발표(특히 AI·데이터)는 “지금 Google이 무엇을 팔고 있는지” 질문에 대비.

### E. 영어

- CE 공고·면접은 영어 사용 가능성이 있다. (프로필 중에도 영어 레벨 표기가 다양함.)  
- **본인 강점이면** 그대로 노출; 약점이면 **기술 영어 프레젠테이션·화이트보드 연습**을 별도로 잡는다.

### F. 이력서·지원 서류

- **AWS 경험 → GCP 매핑 테이블** (서비스 대응 + 마이그레이션 시 고려점).
- “솔루션 아키텍트/프리세일즈에 가까운 성과”를 **수치·규모·고객 유형**으로 구체화 (가능한 범위 내).

---

## 2. 자격증을 어떻게 둘 것인가

- **ACE:** **시험은 보지 않고**, **시험 가이드·커리큘럼으로만** 전 범위 기초를 돌린다 (현재 플랜 확정).
- **PCA (Professional Cloud Architect):** 위 기초 후 **응시하는 공식 자격**으로 둔다. KR CE 프로필과도 잘 맞는다.
- **CKAD:** **현재 플랜에서 제외** (원하면 입사 후 등으로 재검토). 프로필 관찰상 많이 보이지만 필수는 아님.
- **Skills Boost 배지 등:** K8s·GCP 실습 증빙으로 보완 가능.
